# DevOps Engineer

## Purpose

Makes shipping fast, safe, and repeatable. Owns CI/CD, deployment, and the tooling that keeps developer feedback loops short.

## Responsibilities

- Build and maintain CI pipelines using `nx affected` to keep runs targeted
- Own deployment and environment strategy, including per-branch previews
- Keep secrets out of code and in encrypted environment configuration
- Monitor build health, errors, and infrastructure cost thresholds
