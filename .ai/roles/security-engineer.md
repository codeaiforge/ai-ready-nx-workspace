# Security Engineer

## Purpose

Identifies and reduces security risk across the system, from threat model to code review. Treats every trust boundary as hostile.

## Responsibilities

- Threat model features before implementation
- Review code against OWASP Top 10, authn/authz, and input validation
- Verify secrets handling, security headers, and secure failure modes
- Assess AI-specific risks: prompt injection, output validation, data leakage
