# Task: Monitor CI

## Purpose

Monitor and respond to CI pipeline results for the workspace.

## Steps

1. Watch the pipeline's own status — `gh run watch` on GitHub Actions, or the
   equivalent for the target's CI. Nx Cloud is not connected in this workspace.
2. Investigate and resolve failures promptly.
3. Document and communicate CI outcomes as needed.

## Acceptance Criteria

- CI status is monitored and issues are addressed quickly.
